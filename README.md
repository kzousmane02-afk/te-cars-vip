# TE Cars VIP

Application de gestion de flotte et de chauffeurs, utilisable sur téléphone et ordinateur, avec ou sans internet.

## Publication sur GitHub Pages

Le déploiement se fait via le workflow GitHub Actions `.github/workflows/pages.yml`. Dans les paramètres du dépôt, activez **Settings → Pages → Build and deployment → Source: GitHub Actions**. Après le premier déploiement, le site sera disponible à l’adresse :

https://kzousmane02-afk.github.io/te-cars-vip/

Les fichiers de l’application doivent être à la racine du dépôt (`index.html`, `sw.js`, `manifest.webmanifest` et les icônes PNG référencées par le manifeste).
